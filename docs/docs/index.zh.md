# DanLing

DanLing 为机器学习研究提供训练运行器、变长张量、指标和常用工具。

API 参考使用英文，包含当前接口的参数、行为说明和示例：

- [公共接口目录](https://danling.org/package/)
- [Runners：训练、评估与推理](https://danling.org/runners/)
- [Tensors：变长张量与 PyTorch 集成](https://danling.org/tensors/)
- [Optim：学习率调度](https://danling.org/optim/lr_scheduler/)
- [Metrics：数据集指标与流式指标](https://danling.org/metrics/)
- [Utils：序列化与文件读取](https://danling.org/utils/io/)
